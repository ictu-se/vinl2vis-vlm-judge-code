# Difficulty-Normalized 160-Case Slice

This slice is derived from the 240-case calibration package to reduce ceiling and floor effects in the main paper tables. It keeps all non-easy cases identified from model-assisted labels and adds a controlled sample of easy-positive cases across source buckets.

Composition by difficulty band:

- boundary: 28
- easy_positive: 65
- hard_or_bad: 7
- strong_disagreement: 60

Composition by source bucket:

- cross_judge_disagreement: 13
- deterministic_failure: 22
- primary_vlm_flagged: 40
- supplemental_vlm_consensus_accepted: 20
- vlm_consensus_accepted: 43
- weak_judge_only_flag: 22
